# nc_automations

This extension adds civi rules and hooks to manage data transformation on actions taken by the administrator.
These actions propagate data transformations for individuals and organizations.
The aim of this extension is to keep the data representation of these contacts as accurate as possible and as
immediately as possible.

This is an [extension for CiviCRM](https://docs.civicrm.org/sysadmin/en/latest/customize/extensions/), licensed
under [AGPL-3.0](LICENSE.txt).

## Getting Started

Install and enable the module by running:

*cv flush && drush cr && cv en nc_automations*

then navigate to <your-site>/civicrm/civirules/form/rulesview and enable the civi rules.
